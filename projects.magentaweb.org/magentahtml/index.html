MagentaHTML Tags & Attribute Übersicht

MagentaHTML ist eine eigene Erweiterung bzw. Variation von HTML, entwickelt für MagentaWeb-Projekte. Es behält die Grundprinzipien von HTML bei, erweitert aber die Möglichkeiten für strukturiertes Layout, interaktive Inhalte und native MagentaWeb-Komponenten.
