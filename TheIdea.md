# MagentaWeb

## Deutsch – Idee hinter MagentaWeb

### **Was ist MagentaWeb?**
MagentaWeb ist ein vollständig neu entwickeltes Web-Ökosystem, das das heutige Internet vereinfacht, modernisiert und vereinheitlicht.  
Es ersetzt alle klassischen Webtechnologien durch ein logisches, leicht erlernbares System.

### **Ziel**
MagentaWeb soll es jedem ermöglichen, Websites, Apps und APIs so einfach wie möglich zu erstellen – ohne komplizierte Syntax, ohne Chaos und ohne externe Abhängigkeiten.

### **Kernkomponenten**
| Klassisches Web | MagentaWeb |
|------------------|-------------|
| HTML | MagentaHTML |
| CSS | MagentaStyle |
| JavaScript | MagentaScript |
| JSON / TOML / Datenbanken | MagentaData |
| PHP / Node.js | MagentaBackend |
| Browser (Chrome, Edge, Firefox…) | MagentaBrowser |

### **Philosophie**
- **Einfachheit:** Logische, klare Syntax für jeden.  
- **Konsistenz:** Einheitliche Struktur über alle Module.  
- **Intelligenz:** Automatische Optimierungen und intelligente Verarbeitung.

### **Langfristige Vision**
Ein Websystem, das Websites, Apps und APIs in einer Sprache vereint, und das weltweit als offener Standard verfügbar ist.

## English – The Idea Behind MagentaWeb

### **What is MagentaWeb?**
MagentaWeb is a completely new web ecosystem that simplifies, modernizes, and unifies today’s Internet.
